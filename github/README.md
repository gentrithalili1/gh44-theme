# gh44 for GitHub

A [Stylus](https://add0n.com/stylus.html) userstyle for GitHub's interface,
diffs and code. It follows GitHub's appearance setting, including **Sync with
system**. Code uses the same colors as Zed.

## Install

1. Install [Stylus](https://add0n.com/stylus.html).
2. Open **[gh44.user.css](https://raw.githubusercontent.com/gentrithalili1/gh44-theme/main/github/gh44.user.css)** and click **Install style**.
3. Reload GitHub.

## Update

Open the same link and click **Reinstall style**. GitHub caches raw files for
about 5 minutes after a push.

## Edit

These files are generated. Edit [`palette/tokens.json`](../palette/tokens.json) and run `node scripts/build.mjs` from the repository root.
